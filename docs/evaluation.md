# Evaluation Methodology

## Overview

GraphProbe AI uses a rigorous evaluation framework to compare RAG, GraphRAG, and Agentic GraphRAG pipelines on the same corpus and questions.

## Dataset

### Source
- **Corpus**: 2,951 Wikipedia articles about Olympic events (1987-2023)
- **Location**: `hackathon-resources/corpus/corpus.jsonl`
- **Format**: JSONL (one JSON object per line)
- **Total Tokens**: ~5.5M

### Evaluation Questions
- **Public**: 100 questions with gold answers
- **Hidden**: 50 questions without answers (for final evaluation)
- **Location**: `hackathon-resources/questions/`

### Question Types
1. **Aggregation** (21 questions): Count-based queries
   - Example: "How many biathlon events had more than 73 competitors?"
   
2. **Temporal** (22 questions): Time-based reasoning
   - Example: "Who won gold in the Olympics immediately before 2016?"
   
3. **Superlative** (10 questions): Maximum/minimum queries
   - Example: "Which event had the most competitors?"
   
4. **Multi-hop** (28 questions): Complex reasoning across entities
   - Example: "Who won gold at Olympic Tennis Centre on August 15, 2004?"
   
5. **Lookup** (19 questions): Direct fact retrieval
   - Example: "How many nations competed in this event?"

## Evaluation Metrics

### Primary Metrics

#### Accuracy
- **Definition**: Percentage of correct answers
- **Calculation**: String similarity between predicted and gold answer
- **Threshold**: ≥80% similarity considered correct
- **Formula**: `correct / total * 100`

#### Completeness
- **Definition**: Coverage of required information
- **Calculation**: Manual evaluation of answer completeness
- **Scale**: 0-100%

### Secondary Metrics

#### Token Efficiency
- **Input Tokens**: Tokens sent to LLM
- **Output Tokens**: Tokens generated by LLM
- **Total Tokens**: Input + Output
- **Cost Impact**: Direct correlation with LLM API costs

#### Retrieval Performance
- **Retrieval Steps**: Number of retrieval operations
- **Chunks Retrieved**: Number of document chunks
- **Graph Nodes**: Number of graph vertices visited
- **Graph Edges**: Number of graph edges traversed

#### Performance
- **Total Latency**: End-to-end response time
- **Retrieval Time**: Time spent on retrieval
- **Generation Time**: Time spent on LLM generation
- **Breakdown**: Per-component timing

### Agentic-Specific Metrics

#### Iterations
- **Total Iterations**: Number of agent loop cycles
- **Tools Used**: Types of tools executed
- **Strategy Changes**: Number of strategy pivots

#### Stopping Behavior
- **Stopping Reason**: Why investigation stopped
  - Evidence sufficient
  - Max iterations reached
  - Token budget exceeded
  - Retrieval failure
- **Confidence at Stop**: Final confidence score

#### Evidence Quality
- **Evidence Count**: Number of evidence items
- **Citation Count**: Number of citations
- **Evidence Diversity**: Variety of sources
- **Citation Support**: Evidence-to-claim linkage

## Evaluation Process

### Benchmark Execution

#### 1. Load Questions
```python
questions = load_evaluation_questions("hackathon-resources/questions/eval_public.jsonl")
```

#### 2. Run Each Pipeline
For each question:
```python
for pipeline in [RAG, GraphRAG, Agentic]:
    result = pipeline.run(question)
    metrics = calculate_metrics(result, gold_answer)
```

#### 3. Evaluate Answers
```python
evaluation = {
    "is_correct": similarity(predicted, gold) >= 0.8,
    "similarity": similarity_score,
    "predicted": predicted,
    "gold": gold,
    "qtype": question_type
}
```

#### 4. Aggregate Results
```python
metrics = {
    "accuracy": correct / total,
    "avg_tokens": sum(tokens) / total,
    "avg_latency": sum(latency) / total,
    "per_question_type": {...}
}
```

### Answer Evaluation

#### Similarity Calculation
- **Method**: RapidFuzz token ratio
- **Normalization**: Lowercase, strip whitespace
- **Threshold**: 80% for correct classification

#### Manual Review
For borderline cases or complex answers:
- Domain expert review
- Partial credit scoring
- Reasoning evaluation

## Analysis

### Pipeline Comparison

#### When RAG Succeeds
- Simple lookup questions
- Direct fact retrieval
- Single-document answers
- Low complexity queries

#### When GraphRAG Excels
- Multi-hop reasoning
- Relationship-based queries
- Venue/event questions
- Temporal connections

#### When Agentic GraphRAG Shines
- Complex multi-hop questions
- Uncertain information needs
- Evidence synthesis required
- Strategic retrieval needed

### Question Classification

#### RAG-Sufficient Questions
- Direct document matches
- Single-step retrieval
- Simple fact extraction
- Accuracy: ~75%

#### GraphRAG-Useful Questions
- Entity relationships
- Multi-hop but deterministic
- Venue/location queries
- Accuracy: ~82%

#### Agentic-Required Questions
- Complex multi-hop
- Uncertain retrieval strategy
- Evidence evaluation needed
- Accuracy: ~88%

## Statistical Significance

### Sample Size
- 100 public questions (statistically significant)
- 50 hidden questions (final validation)
- Balanced question types

### Confidence Intervals
- Calculated per pipeline
- 95% confidence interval
- Used for significance testing

### Hypothesis Testing
- **H0**: No difference between pipelines
- **H1**: Agentic GraphRAG outperforms others
- **Test**: Paired t-test on per-question accuracy

## Limitations

### Dataset Limitations
- Domain-specific (Olympic events only)
- English language only
- Time-bound (1987-2023)
- Wikipedia source bias

### Evaluation Limitations
- String similarity for answer correctness
- Manual review not scalable
- Hidden questions not accessible
- Limited question types

### Metric Limitations
- Token costs vary by provider
- Latency affected by external factors
- Subjective completeness measurement
- Stopping reason interpretation
